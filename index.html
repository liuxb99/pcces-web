功能特色

完整的工程經費管理工具

涵蓋公共工程經費估算、預算編列、報價管理、Excel 匯出等完整功能。

💰

經費估算

依 PCCES 標準進行工程經費估算，支援多種工項模板與單價分析。

📋

預算編列

工程預算編列與管理，支援直接工程費、間接工程費、利潤管理等。

📊

報價管理

廠商報價登錄、比價分析、最低標/最有利標評選輔助。

📄

Excel 匯出

一鍵匯出標準 PCCES 格式 Excel，符合公共工程委員會規範。

🔐

會員系統

JWT 認證、會員分級管理，支援資料庫持久化儲存。

⚙️

C# 核心引擎

底層計算引擎使用 C# 實作，確保與 PCCES 桌面版完全相容。

技術棧

全端 Web 技術

Flask + React 前後端分離架構，部署於 Vercel Serverless 平台。
