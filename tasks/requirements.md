# 用戶需求：PCCES 網頁版

## 原始需求
> 要做一個網頁版的 PCCES，源碼在資料夾裡面，要做的比原版 PCCES 更好幾個等級。

## 原始 PCCES 功能概述
PCCES（公共工程經費估算系統）是一套 C# WinForms 桌面應用程式，主要功能包括：

1. **使用者管理** — 登入、註冊、權限控管
2. **儀表板** — 首頁面板、快捷功能紐、最新消息
3. **專案管理** — 建立、編輯、切換專案
4. **預算編輯** — 核心功能
   - 樹狀預算項目結構（WBS）
   - 表格化編輯（類似 Excel）
   - 數量 × 單價 = 總價自動計算
   - 成本架構管理
   - 工、料、機資源管理
   - 資源單價設定
5. **預算變更管理** — 變更單、變更歷史、差異比較
6. **投標管理** — 標單、比價
7. **報表系統** — Excel 匯出、PDF 產生、總表、詳細表、成本分析表
8. **系統維護** — 資料庫升級、同步

## 網頁版需提升的重點
1. **UI/UX 大升級** — 從老舊 WinForms 改為現代化響應式設計，支援深色模式
2. **即時計算** — 編輯時即時更新總價
3. **互動圖表** — 成本分布、趨勢分析
4. **雲端協作** — 多人在線，角色權限分明
5. **智慧報表** — 即時預覽 PDF/Excel，互動式報表
6. **版本控制** — 預算版本比較、變更軌跡
7. **無需安裝** — 瀏覽器即可使用

## 技術需求
- 前端：React + TypeScript + Ant Design
- 後端：Python FastAPI
- 資料庫：SQLite（開發）/ PostgreSQL（生產）
- 認證：JWT
