# 用戶需求 V2：示範資料與實際操作體驗

## 需求
目前 PCCES 網頁版功能齊全但資料庫是空的，使用者一登入什麼都看不到。
需要加入起始示範資料，讓使用者一開啟就能看到實際的專案、預算項目、資源，
可以直接操作體驗。

## 具體要求
1. 應用啟動時自動檢測資料庫是否為空
2. 若為空則自動建立一筆示範專案，包含：
   - 示範專案（例如「OO 大樓新建工程」）
   - 至少 3 層預算樹狀結構（總表 → 直接工程費 → 各工項）
   - 至少 5 個預算子項，包含 B、W 類型
   - 至少 3 筆資源（工、料、機各一筆）
3. 前端在載入完成後自動顯示資料，不是空白的儀表板
4. 使用者可以自由修改或刪除這些示範資料
