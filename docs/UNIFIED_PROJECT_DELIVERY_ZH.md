# AI 工程顧問公司統一專案交付規範

本專案最終必須產生專案成果網站，所有 PCCES Web 預算、工料機、單價分析、數量來源、版本差異與匯出檔均由網站統一展示、下載與交接。

流程：需求與知識圖譜 → CLI 中文 Markdown 草案 → 使用者調整 → Schema／工程規則驗證 → 權威中間模型 → 專業成果 → 專案網站 → 驗收與交接。

中文 Markdown 是人工可編輯契約；中間模型是機器權威資料；網站是唯一正式入口。工項 ID 必須可對照數量、構件、圖面與排程。

網站需含預算摘要、工料機、單價分析、驗證中心、下載中心與交接中心。發布狀態與驗收不得以網站可開啟代替專業驗收。

最低驗收：成果同版本、連結有效、Manifest／SHA256 可核對、狀態真實、無敏感資訊、接收者可獨立接續。

公司級權威規格：`AI-Company-Handbook/07-Work-Delivery/docs/AI_ENGINEERING_PROJECT_DELIVERY_STANDARD_ZH.md`。
